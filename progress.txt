# Ralph Progress Log - AI News Aggregator

## Project Overview
AI News Aggregator & Newsletter Platform - Curated AI news from top newsletters and blogs, deduplicated and delivered as personalized email digests.

## Tech Stack
- Frontend: Next.js 14 (App Router) + Tailwind CSS
- Backend: Next.js API Routes
- Database: Supabase (PostgreSQL)
- Email Delivery: Resend + React Email
- AI Processing: Claude API (content extraction)
- Email Ingestion: Mailgun Inbound Routing
- Hosting: Vercel

## Codebase Patterns
- Project uses src/ directory structure with App Router
- TypeScript strict mode enabled
- Tailwind CSS for styling
- Inter font as default
- Supabase clients: use `createClient()` from `@/lib/supabase/client` for browser, `@/lib/supabase/server` for server-side
- Use `createServiceRoleClient()` for admin operations that bypass RLS
- Migrations: `supabase/migrations/YYYYMMDDHHMMSS_description.sql` format
- Use `IF NOT EXISTS` for tables/indexes to make migrations idempotent
- Reuse `update_updated_at_column()` trigger function for updated_at columns

## 2026-02-11 - US-005
- **Implemented:** Create users table schema
- **Files created:**
  - supabase/migrations/20260211000003_create_users_table.sql
- **Schema details:**
  - Created `email_frequency` enum with values: 'daily', 'weekly'
  - Table columns: id (UUID PK), email (text unique), email_verified (default false), verification_token, unsubscribe_token (unique), frequency (email_frequency enum default 'daily'), is_active (default true), signed_up_at, last_email_sent_at, created_at
  - Indexes: idx_users_email, idx_users_active_frequency (partial index WHERE is_active=true), idx_users_unsubscribe_token (partial index WHERE NOT NULL)
- **Learnings for future iterations:**
  - Partial indexes (with WHERE clause) can optimize specific query patterns
  - `idx_users_active_frequency` uses partial index to only index active users, optimizing digest batch queries
  - `idx_users_unsubscribe_token` uses partial index to skip NULL values, as most lookups only need non-null tokens

- **Learnings for future iterations:**
