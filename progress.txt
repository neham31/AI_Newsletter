# Ralph Progress Log - AI News Aggregator

## Project Overview
AI News Aggregator & Newsletter Platform - Curated AI news from top newsletters and blogs, deduplicated and delivered as personalized email digests.

## Tech Stack
- Frontend: Next.js 14 (App Router) + Tailwind CSS
- Backend: Next.js API Routes
- Database: Supabase (PostgreSQL)
- Email Delivery: Resend + React Email
- AI Processing: Claude API (content extraction)
- Email Ingestion: Mailgun Inbound Routing
- Hosting: Vercel

## Codebase Patterns
- Project uses src/ directory structure with App Router
- TypeScript strict mode enabled
- Tailwind CSS for styling
- Inter font as default
- Supabase clients: use `createClient()` from `@/lib/supabase/client` for browser, `@/lib/supabase/server` for server-side
- Use `createServiceRoleClient()` for admin operations that bypass RLS
